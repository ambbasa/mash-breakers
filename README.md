# MASH BREAKERS ⚡

**90년대 오락실 초인 스포츠의 손맛을 현대 웹으로 재해석한 2D 레트로 아케이드 게임**

HTML5 Canvas 기반의 초경량 웹게임으로, PC 키보드와 모바일 터치 모두에서 별도 설치 없이 바로 플레이할 수 있습니다. Poki / CrazyGames 등 글로벌 웹게임 포털 출시 및 광고 수익화를 염두에 두고 설계되었습니다.

---

## 🎮 주요 특징

- **핵심 3종목 + 3-Event Arcade Cup**
  1. **MACH SPRINT (100m 음속 질주)**: `A / D` 교대 연타 + `SPACE` 소닉 붐 부스트
  2. **METEOR BREAKER (거대 운석 격파)**: 5초 폭풍 연타 충전 + 타이밍 어퍼컷
  3. **TRAIN STOP (폭주 열차 멈추기)**: 999km/h 열차 정면 캐치 + 극한 연타 브레이크
- **개성 있는 초인 캐릭터 3인**: `REX VOLT` (스피드) / `HANA KAGE` (연타) / `BRUNO IRON` (파워)
- **오락실 타격감(Game Feel)**: 트라우마 셰이크, 히트스톱, 속도선, `MEGA MASH!!` 피버 오라, Web Audio 신스 사운드
- **접근성 & 포털 SDK 대응**: FX 강도 조절(`100% / LOW / OFF`), 음소거, Poki/CrazyGames SDK 어댑터 및 보상형 광고 시뮬레이터 내장

---

## 🚀 실행 방법

빌드 과정 없이 바로 실행할 수 있습니다.

1. 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 브라우저(Chrome, Edge, Safari 등)로 엽니다.

### 조작법
- **연타 (MASH L / R)**: `A` / `D` 또는 `←` / `→` 또는 `Z` / `X`
- **액션 / 결정**: `Space` 또는 `Enter`
- **모바일 / 마우스**: 화면 하단 아케이드 버튼 터치·클릭
