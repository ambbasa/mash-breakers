# MASH BREAKERS — 게임 기획서 (Game Design Document)

> **버전**: v1.0 (MVP Prototype 기준)  
> **장르**: 2D 레트로 아케이드 초인 스포츠 / 버튼 연타 액션  
> **플랫폼**: Web (HTML5 Canvas — PC & 모바일 브라우저 동시 지원)  
> **목표 출시 채널**: 글로벌 웹게임 포털 (Poki, CrazyGames, itch.io) 및 자체 웹  

---

## 1. 프로젝트 개요 (Executive Summary)

### 1.1 한 줄 컨셉
**"90년대 오락실 초인 스포츠의 짜릿한 연타 손맛을, 설치 없이 3초 만에 즐기는 글로벌 웹 아케이드 게임"**

### 1.2 핵심 가치 (Core Pillars)
1. **3초 이해, 30초 몰입**: 별도 튜토리얼 없이 화면만 보고 바로 `A/D` 연타 + `SPACE` 타이밍을 이해할 수 있는 직관성.
2. **과장된 초인 스케일**: 일반 육상이 아닌 *음속 질주*, *맨주먹 운석 격파*, *폭주 열차 멈추기* 등 보는 것만으로 웃음과 카타르시스를 주는 연출.
3. **압도적인 타격감(Game Feel)**: 트라우마 기반 카메라 흔들림, 히트스톱(타격 찰나 정지), 속도선, `MEGA MASH!!` 오라, 레트로 신스 효과음.
4. **포털 최적화 경량 구조**: 3~5초 이내 즉시 로딩, 저사양 모바일/크롬북에서도 60fps 유지.

### 1.3 저작권 및 오리지널리티 원칙
- 수익화(광고·인앱 결제)를 전제로 하므로, 기존 오락실 고전 게임의 명칭·캐릭터·도트·사운드는 일절 사용하지 않습니다.
- 90년대 초인 아케이드 스포츠 장르의 **정신적 후속작(오마주)**으로서 모든 캐릭터, 종목, 비주얼, 사운드를 100% 오리지널로 제작합니다.
- 상표권 이슈를 피하기 위해 *Olympic / Olympics* 단어는 사용하지 않습니다.

## 2. 코어 게임플레이 & 조작 체계

### 2.1 코어 루프 (Core Loop)
```
[타이틀] → [초인 캐릭터 선택] → [모드 선택: 3종목 아케이드 컵 / 단일 종목]
   ↓
[3-2-1 카운트다운] → [광속 연타 + 결정적 타이밍 액션] → [MEGA MASH!! 피버 발동]
   ↓
[기록 측정 & 메달 판정 (FAIL / BRONZE / SILVER / GOLD / S-RANK)]
   ↓
[다음 종목 진행] 또는 [일반 재도전] 또는 [📺 보상형 광고 보고 +10% 파워 재도전]
   ↓
[최종 컵 총점 집계 & 최고 기록 갱신]
```

### 2.2 PC & 모바일 듀얼 조작
| 입력 | PC 키보드 | 모바일 / 터치 UI | 역할 |
|---|---|---|---|
| **MASH L** | `A` / `←` / `Z` | 하단 좌측 대형 레드 버튼 | 좌측 연타 / 메뉴 좌측 이동 |
| **MASH R** | `D` / `→` / `X` | 하단 우측 대형 블루 버튼 | 우측 연타 / 메뉴 우측 이동 |
| **ACTION** | `Space` / `Enter` | 하단 중앙 옐로우 버튼 | 타이밍 액션(부스트·어퍼컷·캐치) / 결정 |

- **교대 연타 보너스**: `L → R → L → R`로 번갈아 누를 때 최대 효율(100%), 같은 키만 연타 시 약 40~45% 효율로 설계하여 리듬감 있는 연타를 유도합니다.
- **안티-홀드(Anti-Hold)**: `keydown` 이벤트의 `e.repeat`를 차단하여 키를 꾹 누르는 꼼수를 방지합니다.

### 2.3 타격감(Game Feel) 및 접근성 스펙
- **트라우마 기반 셰이크**: `shake = trauma²` 공식을 적용해 약한 연타는 미세하게, 대형 임팩트(운석 격파·열차 캐치)는 강렬하게 흔들리며 **실시간(Real-Time) 기준 감쇠**로 히트스톱 중에도 카메라가 어긋나지 않습니다.
- **오버래핑 안전 히트스톱**: 짧은 간격으로 여러 타격이 겹쳐도 타임스케일이 영구 정지되지 않고 최신 호출 기준으로 안전하게 `1.0` 복구됩니다.
- **접근성(Accessibility)**:
  - 광과민성 안전(WCAG 2.3.1): 화면 플래시 효과를 초당 3회 이하로 강제 제한.
  - 상단 UI에 **FX 강도 토글(`100%` → `LOW` → `OFF`)** 및 **사운드 음소거 토글** 상시 제공.

## 3. 종목 설계 (Events Design)

### 3.1 MVP 구현 완료 3종목

| # | 종목명 | 컨셉 및 플레이 방식 | 합격 기준 (BRONZE) | GOLD / S-RANK |
|---|---|---|---|---|
| 1 | **MACH SPRINT**<br>(100m 음속 질주) | `A/D` 교대 연타로 음속 돌파. 40~76m 구간에 등장하는 타이밍 바 중앙에서 `SPACE`를 누르면 **SONIC BOOM** 대폭 가속. | `< 4.50초` | `< 3.55초` / `< 3.15초` |
| 2 | **METEOR BREAKER**<br>(거대 운석 격파) | 5초간 연타로 **GIGA POWER** 충전(`MEGA MASH!!` 도달 가능). 직후 왕복하는 타이밍 바의 시안(중앙) 존에서 `SPACE` 어퍼컷으로 운석 격파. | `300+ TONS` | `560+` / `700+ TONS` |
| 3 | **TRAIN STOP**<br>(폭주 열차 멈추기) | 999km/h 열차가 노란 **CATCH ZONE**에 진입할 때 `SPACE`로 정면 캐치(퍼펙트 시 초기 속도 대폭 감소). 이후 폭풍 연타로 위험선 앞에서 정지. | `5.0m+ 남김` | `22.0m+` / `30.0m+` |

### 3.2 확장 종목 로드맵 (Phase 2~3 후보 6종)
1. **MISSILE THROW (대륙간 미사일 투척)**: 연타로 추진력 충전 + 발사 각도(45° 최적) 타이밍 맞춰 장거리 투척.
2. **MONSTER TUG (거대 괴수 줄다리기)**: 화면 반대편 괴수의 공격 타이밍에 `SPACE`로 버티고, 빈틈에 폭풍 연타로 끌어오기.
3. **GLACIER SPLIT (초거대 빙하 가르기)**: 연속 3회 타이밍 타격 + 마지막 연타 피니시로 빙하 절단 깊이 겨루기.
4. **HYPER HURDLE (초음속 허들)**: 고속 질주 중 대형 장애물(버스·컨테이너)을 `SPACE`로 뛰어넘는 리듬+연타 혼합 종목.
5. **SKY VAULT (성층권 높이뛰기)**: 조주 연타 후 장대 꽂기·도약 2단 타이밍으로 우주 경계선 돌파.
6. **TITAN LIFT (거대 댐/전함 들어올리기)**: 3단계 무게 구간을 연타로 끌어올리며 균형 게이지 유지.

## 5. 아트 & 사운드 디렉션

### 5.1 비주얼 컨셉
- **해상도**: 기준 16:9 (`960 × 540`) 캔버스, 반응형 스케일링 및 `image-rendering: pixelated`.
- **색채**: 90년대 남코/캡콤 아케이드 특유의 고채도 블루 스카이·선셋 오렌지·네온 나이트 경기장 + 생동감 있는 관중석 애니메이션.
- **진화 방향**: 현재 프로토타입의 프로시저럴 픽셀 아트를 바탕으로, Phase 2에서 전용 스프라이트 시트(걷기·질주·기합·표정 컷인·승리/패배 포즈)로 업그레이드.

### 5.2 사운드 디렉션
- **현재**: 외부 오디오 파일 0KB, Web Audio API 기반 실시간 레트로 신스 효과음 (카운트다운, 연타 피치 상승, 소닉 부스트, 묵직한 임팩트, 열차 마찰음, 승리/실패 징글).
- **확장**: 90년대 FM 신스 스타일의 아케이드 BGM 3트랙(타이틀/선택, 경기 메인, 피버) 및 아나운서 보이스 팩(`READY!`, `GO!`, `MEGA MASH!!`, `NEW RECORD!`).

## 6. 수익화 및 포털 출시 전략 (Monetization & Distribution)

### 6.1 1차 타겟 플랫폼: 글로벌 웹게임 포털
자체 마케팅 비용 없이 대규모 유기적 트래픽을 확보할 수 있는 **Poki** 및 **CrazyGames** 입점을 1차 목표로 합니다.

- **포털 입점 필수 체크리스트**:
  - [x] 초기 로딩 경량화 (현재 전체 용량 < 100KB, 최종 목표 < 5MB)
  - [x] PC 키보드 + 모바일 터치 동시 대응
  - [x] `SDK.gameplayStart()` / `SDK.gameplayStop()` 라이프사이클 훅 내장 (`src/sdk.js`)
  - [x] 음소거 토글 및 광고 중 입력 차단 (`SDK.isAdActive()`)
  - [ ] 실제 Poki SDK / CrazyGames SDK 스크립트 연결 및 포털 QA 테스트
  - [ ] 다국어 UI 지원 (최소 영어 기본 + 한국어·일본어·스페인어)

### 6.2 광고 배치 전략 (유저 경험 저해 최소화)
1. **보상형 광고 (Rewarded Video — 핵심 수익원)**:
   - **실패/아쉬운 기록 시 `+10% SUPER POWER` 재도전** *(프로토타입 구현 완료)*
   - **히든 캐릭터 / 코스튬 1판 무료 체험**
   - **데일리 챌린지 추가 도전권**
2. **전면 광고 (Commercial Break — 자연스러운 전환 시점)**:
   - 3종목 컵 완주 후 로비 복귀 시 (최소 2~3분 간격 쿨다운 적용, 경기 도중 절대 노출 금지)

### 6.3 리텐션 & 바이럴 확장 (Phase 3~4)
- **글로벌/일간 리더보드**: Firebase / Supabase 경량 백엔드로 종목별 TOP 100 및 내 백분위 표시.
- **고스트 대결**: 상위 랭커 또는 친구의 기록을 반투명 고스트 캐릭터로 트랙에 함께 표시.
- **실시간 2~4인 링크 대전**: 방 링크 하나로 친구들과 즉시 연타 대결(유튜브/트위치 스트리머·커뮤니티 바이럴 핵심).

## 7. 기술 아키텍처 & 개발 로드맵

### 7.1 현재 프로젝트 구조
```text
mash-breakers/
├── index.html          # 반응형 16:9 아케이드 쉘 & 모바일 터치 덱
├── style.css           # 레트로 아케이드 UI 스타일
├── src/
│   ├── sdk.js          # Poki / CrazyGames 포털 SDK 어댑터 + 로컬 광고 시뮬레이터
│   ├── audio.js        # Web Audio API 레트로 신스 효과음 엔진
│   ├── juice.js        # 트라우마 셰이크, 히트스톱, 플래시 제한, 파티클/스피드라인
│   ├── sprites.js      # 초인 캐릭터 3인 & 경기장/운석/열차 프로시저럴 렌더러
│   ├── events.js       # 핵심 3종목 게임플레이 로직 & 메달/점수 판정
│   └── main.js         # 타이틀·선택·경기·결과·컵 요약 상태 머신 & 로컬 랭킹
└── docs/
    └── GAME_DESIGN_DOCUMENT.md
```

### 7.2 마일스톤 로드맵
- **Phase 1 — 코어 프로토타입 (완료 ✅)**
  - 핵심 3종목, 캐릭터 3명, 3-Event Cup, Juice 엔진, Web Audio, 포털 SDK 어댑터, 로컬 하이스코어.
- **Phase 2 — 아케이드 폴리싱 (2~3주)**
  - 전용 도트 스프라이트 시트 & 캐릭터 표정 컷인 추가.
  - 레트로 BGM & 아나운서 보이스 추가.
  - 확장 종목 2~3개 추가(총 5~6종목) 및 밸런스 튜닝.
- **Phase 3 — 포털 출시 준비 (1~2주)**
  - Poki / CrazyGames SDK 실연동, 영문/다국어 UI 정리, 모바일 브라우저(iOS Safari / Android Chrome) QA.
  - itch.io 선공개로 초기 유저 피드백 및 리텐션 데이터 수집.
- **Phase 4 — 글로벌 런칭 & 라이브 확장**
  - Poki / CrazyGames 정식 제출 및 런칭.
  - 글로벌 리더보드, 데일리 챌린지, 친구 대전 모드 업데이트.
